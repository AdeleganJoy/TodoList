# 📝 TodoList
This is a project created in October 2023.
A user-authenticated to-do list app with registration, login, and persistent task management using Node.js, Express, MongoDB, and JWT.

## 📋 Features

This project helps users with:
- User registration and secure login using JWT authentication
- Creating, updating, and retrieving their personalized todo lists
- Validating input data for registration and login
- Protecting routes to ensure only authenticated users can access their data

## ⚙️ Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/AdeleganJoy/TodoList.git
     ```
   
2. **Navigate to the project directory**:
   ```bash
   cd TodoList
     ```
   
3. **Install npm dependencies**:
   ```bash
   npm install
     ```
   
4. **Run TodoList webpage**
   ```bash
   npm start
